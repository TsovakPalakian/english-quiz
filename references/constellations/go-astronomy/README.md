# Go Astronomy: 88 constellation charts

Original JPEG charts downloaded on 2026-10-24 for local comparison. Each file is named after its constellation abbreviation, for example `Cnc.jpg` (Cancer) and `Gem.jpg` (Gemini).

Source: https://www.go-astronomy.com/constellations.php

`manifest.json` lists all 88 constellation names, original page/image URLs and SHA-256 hashes. These are original images, not application screenshots.

The images belong to their respective rights holders. No public redistribution licence has been established. This reference folder is not included in the website build; public distribution requires checking the rights separately.
