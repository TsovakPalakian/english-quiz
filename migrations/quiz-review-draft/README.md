# Черновая схема проверки квизов

Только для отдельной локальной тестовой базы после существующей learning-схемы. **Не применять к production и не включать в migrations/learning без отдельного согласования.** Автоматического применения нет.

Реализация: `src/quiz-review.mjs`, проверка содержимого: `src/quiz-review-content.mjs`.

Проверка: `node --test test/test-quiz-review.mjs`. Каждый тест создаёт отдельную SQLite-базу в памяти. Тест D1 использует существующий D1StudyClient поверх SQLite-совместимой тестовой привязки: проверяет компиляцию и транзакции, но не означает проверку на реальном Cloudflare D1.

## Контракт

- Сервис получает actor только из доверенной аутентификации. Публичных HTTP-маршрутов и подключения UI пока нет.
- Создание значения и явная привязка карточки к значению доступны разработчику. Привязка не выполняется автоматически по одному написанию слова.
- Предложение создаётся только для общей карточки из слова доступного урока в выбранной группе. Учитель должен быть назначен на эту группу; разработчик имеет доступ к активным группам.
- Автор редактирует только draft/returned. Submitted нельзя править: проверяющий возвращает его с комментарием. Это более консервативное ограничение, чем действие Edit draft в демонстрационном UI; при подключении UI их нужно согласовать.
- Отправка, возврат и одобрение проверяют expectedRevision и сохраняют события с копией содержания. Повтор mutationId воспроизводит квитанцию, а другой запрос с тем же ID отклоняется.
- Глобальное одобрение по умолчанию выключено. В тестах включается через allowGlobalApproval; в будущих маршрутах настройка должна поступать только от сервера. Три пункта проверки обязательны. Самоодобрение запрещено.
- Одобренная версия неизменяема, включая SQL UPDATE/DELETE. История событий неизменяема. Исправление создаёт отдельный черновик; новая версия не наследует отметку одобрения.
- Новая версия содержит собственное авторство. Автор исходного шаблона сохраняется в истории и общей выдаче как originalAuthor.
- Общая выдача содержит последнюю одобренную версию каждой семьи, но не скрытые черновики. Несколько квизов одного типа имеют разные familyId. Старые одобренные версии сохраняются.
- Доступ через личную карточку требует явной связи с тем же значением и права читать эту карточку. Общая выдача не раскрывает идентификаторы аккаунтов, исходных уроков, комментарии и внутреннюю историю.
- Даты возвращаются без времени, в формате YYYY-MM-DD, по Asia/Yerevan.

## Ещё не подключено

HTTP/CSRF и лимиты запросов, реальные роли и сессии, публичные правила отображения авторства учеников, миграция старых карточек, UI, фоновые задачи, генератор, отправка почты, проверки реального D1 и production. Структурная проверка всех 17 типов не гарантирует языковую правильность и не заменяет учителя. Публикацию права на глобальное одобрение и раскрытие авторства необходимо согласовать отдельно.
