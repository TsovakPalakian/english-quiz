# План отключения жирного выделения линий созвездия при наведении на название

## Назначение задачи

Исключить утолщение и эффект светящейся тени на линиях созвездия при наведении курсора на название созвездия (`.auth-sky-title`) на астрономическом холсте (`#authSky`). Линии созвездия должны сохранять стандартную базовую толщину (`lineWidth = 0.8`) и прозрачность (`lineAlpha = 0.65`) без теней (`shadowBlur = 0`), обеспечивая визуальное спокойствие и единообразие сцены.

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>: Запрещено задевать, модифицировать или ломать функционал, не относящийся к текущей задаче. Выполняемые задачи строго и изолированно должны задевать только свой функционал (отрисовка соединительных линий созвездия при активном инспекторе без изменения работы карточки созвездия, таймеров скрытия, звездных маркеров и инспектора отдельных звезд).

## Чеклист реализации

- 🟩 Этап 1: Документирование и планирование — создание плана с утвержденными снимками экрана и чеклистом.
- 🟩 Этап 2: Корректировка параметров отрисовки линий созвездия — сохранение `lineWidth = 0.8` и отключение эффекта тени линий при активном созвездии.
- 🟩 Этап 3: Сборка клиентского бандла — вызов `npm run build:preview` для генерации обновленного корневого бандла из модулей.
- 🟩 Этап 4: Написание визуальных и модульных тестов — добавление тестов на толщину линий при инспекции созвездия.
- 🟩 Этап 5: Верификация тестов и чистота репозитория — запуск целевых тестов, проверка отсутствия регрессий и удаление временных скриптов.
