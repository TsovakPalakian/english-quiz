# План отмены ограничений по ошибкам в упражнениях и скрытия таймера в Memory

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>
> **ПРЕДУПРЕЖДЕНИЕ О ЗАТРАГИВАНИИ СМЕЖНОГО ФУНКЦИОНАЛА И НЕПРИКОСНОВЕННОСТИ СИСТЕМЫ:**
> Текущая задача строго изолирована и касается исключительно:
> 1. Скрытия и отключения таймера обратного отсчета (`#dayqTimer`) при запуске и прохождении упражнения Memory («Find the pairs»).
> 2. Удаления лимита ошибок (`misses >= 3`) и аварийной остановки (`markDay(false, "Find the pairs")`) в режиме Memory: при выборе несовпадающей пары карточки автоматически закрываются после короткой паузы, позволяя ученику продолжать попытки до полного нахождения всех пар без прерывания упражнения и без принудительного показа экрана ошибки с кнопкой перехода.
> 3. Удаления лимита ошибок в упражнении Match («Match the pairs»): исключение условия принудительного завершения упражнения при ошибках, обеспечение возможности завершить сопоставление всех пар слов.
> 4. Недопущения прерывания интерактивных тренировочных упражнений по лимиту ошибок: сохранение возможности довести каждое задание до успешного завершения.

> - Алгоритмы интервального повторения FSRS и расчет интервалов карточек.
> - Шапку профиля, замену аватарки на колокольчик и диалог сообщений.
> - Полномочия и разграничение прав ролей пользователей.
> - Экран каталога уроков и материалы чтения.
> - Начисление и сохранение статистики успеваемости и учет ошибочных слов для словаря ошибок.

## 1. Точная формулировка проблемы (Problem Statement)

1. **Принудительная остановка упражнения Memory при ошибках**:
   - В текущей реализации при несовпадении открытой пары карточек инкрементируется счетчик ошибок `misses`. При достижении 3 ошибок (или при режиме экзамена) управление передается в обработчик завершения с параметром `false`, выводя красный блок «Incorrect. Right answer: Find the pairs» и кнопку «Next». Упражнение принудительно прерывается, и ученик лишается возможности доиграть карточки и закрепить слова.
2. **Наличие таймера обратного отсчета в упражнении Memory**:
   - При старте тренировочного блока запускается общий таймер обратного отсчета сессии (`armExamClock`), который активирует плашку таймера `#dayqTimer` над заголовком упражнения (например, `00:15` при бюджете в 30 секунд на упражнение). В игре на запоминание пар наличие тикающего таймера создает стресс и приводит к истечению времени до завершения сопоставления.
3. **Ограничения по ошибкам в других типах упражнений**:
   - В сопоставлении пар Match также установлено ограничение `misses >= 3`, после которого упражнение сбрасывается с пометкой ошибки. Согласно требованию, интерактивные задания не должны преждевременно останавливаться из-за допущенных ошибок.

## 2. Границы области изменений и инварианты (Scope Boundaries & Invariants)

- **Область изменений**:
  - Логика рендеринга и часов сессии: гарантированное скрытие плашки `#dayqTimer` при отображении типа Memory.
  - Обработка клика по карточкам Memory: при несовпадении двух открытых карточек счетчик ошибок может обновляться для внутренней телеметрии, но карточки просто закрываются по таймауту 700 мс без вызова функции прерывания упражнения и без блокировки игрового поля.
  - Обработка сопоставления пар Match: исключение преждевременного прерывания упражнения по лимиту ошибок.
  
- **Инварианты**:
  - Полная поддержка тем оформления через переменные CSS (`--bg`, `--card`, `--ink`, `--mute`, `--line`, `--acc`).
  - Сохранение фиксации правильного ответа при успешном нахождении всех пар (`markDay(true, "")`).
  - Сохранение возможности добавлять новые слова в словарь по клику на иконку книги внутри карточки Memory.

- 🟩 **Этап 1**: Согласование Шаблона 1 (игровой экран Memory без таймера обратного отсчета и без блокирующего красного баннера ошибки; карточки открываются и при несовпадении скрываются обратно без прерывания игры; одобрено пользователем).

- 🟩 **Этап 5**: Сборка клиентских ассетов (`npm run build:preview`).
- 🟩 **Этап 6**: Прогон целевых тестов и визуальной проверки.
- 🟩 **Этап 7**: Итоговый коммит и отчет.
