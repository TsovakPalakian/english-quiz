> Текущая задача строго изолирована и касается исключительно:
> 1. Сохранения исходного порядка вариантов и корректного индекса ответа при передаче готовых пользовательских заданий в функцию `openFocusPlayer`.
> 2. Устранения случайного перемешивания вариантов ответа для пользовательских массивов вопросов, передаваемых напрямую в плеер без флага рандомизации.

> - Порог 90% и адаптивную доработку ошибок в `focusApplyAdaptiveRemediation`.
> - Модуль голосового тьютора Voice Mode и экзаменационный модуль.

## 1. Точная формулировка проблемы (Problem Statement)

1. В функции `openFocusPlayer` при передаче массива готовых вопросов `customQuestions` выполнялся безусловный вызов `shuffleQuestionOptions` и `shuffleArray`.
2. В тестовом сценарии проверки цветовой схемы Focus Mode передается фиксированный вопрос с двумя вариантами ответа `['One', 'Two']` и правильным индексом `answer: 1`.
3. Из-за случайного перемешивания вариантов правильный ответ `'Two'` периодически смещается на нулевую позицию, а на первой позиции оказывается неверный ответ `'One'`.
4. При вызове `focusSelectOption(1)` выбирается неверный ответ, кнопка получает класс ошибки и цвет неудачи (`--bad`: `#ff7a7f` в теме Dark, `#c83b45` в теме Sky) вместо цвета успеха (`--ok`: `#3dd598` в теме Dark, `#1b8a4a` в теме Sky), что приводит к падению теста.

---

## 2. Границы области изменений и инварианты (Scope Boundaries & Invariants)

- **Затрагиваемая логика**:
  - Функция `openFocusPlayer`: для внешних готовых вопросов `customQuestions` сохраняется исходный массив без принудительного перемешивания вариантов.
  - Рандомизация вариантов ответа сохраняется для вопросов, автоматически извлекаемых из блоков урока через `extractFocusQuestionsFromLesson`.
- **Инварианты**:
  - Полная обратная совместимость со всеми режимами запуска Focus Mode.
  - Сохранение 100% работоспособности тестов семантических дистракторов и областей практики.
