## Ограничения
Ссылка R2 требует S3 Access Key ID и Secret Access Key; Wrangler OAuth не заменяет эти ключи. Ручная ссылка ограничена семью днями; новый workflow создаёт собственную 15-минутную ссылку для каждого job, без ручного обновления. Сам R2-токен должен оставаться действительным. Никакие тесты, commit, push или публикация сайта в этот этап не входят.
