## Ход работы

Начат анализ существующих схем блоков, загрузки файлов и серверного PDF API. Существующие незакоммиченные изменения не откатываются.

Реализован `scope=full` для существующего PDF API; прежний режим Title / Description сохранён. Ограничены размер ответа, количество элементов, страницы, варианты ответов и критерии. HTML модели не исполняется.

Предпросмотр показывает разделы, предупреждения, ответы для учителя и ссылки на страницы в виде номеров. Basic information заменяется только при явном выборе. Контент добавляется, существующие блоки не удаляются. Элементы того же PDF узнаются по SHA-256 и ключу раздела; ручные изменения таких элементов не перезаписываются. При применении к опубликованному уроку требуется отдельное согласие на перевод обратно в черновик.

Words используют редактируемые vocabulary-блоки, без автоматического создания карточек общего словаря; Rules — текстовые объяснения, без вымышленных идентификаторов общей грамматики. Обновлены связанные счётчики урока. Homework, группа, дата и Speech practice не изменяются. Образцы открытых ответов доступны учителю; сервер удаляет их из ученического представления, включая baseline. Объективные упражнения используют существующий механизм самопроверки: ключи не отображаются до проверки, но это не защита экзамена от изучения клиентского JSON.

Страницы и педагогическая полнота требуют проверки учителем: AI-анализ не гарантирует безошибочное чтение сканов. Большие уроки ограничены контрактом и лимитом сохранения; интерфейс предложит выбрать меньше разделов вместо обрезания при сохранении.
