# Запуск CI/CD по веткам

🟨 Разрешить push-trigger для всех веток, включая имена со слешем; push тегов не включать.
🟨 Сохранить существующий deploy-gate: только событие push в `refs/heads/main` после успешного test job.
🟨 Ручной workflow_dispatch и push в остальные ветки выполняют тесты и Telegram без деплоя. Прочая подготовка CI не меняется.
⬜ Пользователь проверяет push в отдельную ветку и ручной workflow. Проверка push в main может опубликовать сайт; автоматически не выполняется.

## Результат
В workflow фильтр `[main]` заменён на `['**']`. Условие deploy оставлено без изменений. Тесты, commit, push и публикация агентом не запускались; поведение GitHub ожидает пользовательской проверки.

Сообщение коммита: `Enabled branch push tests while keeping deployment exclusive to main`.
