# История изменений

Здесь хранятся планы и результаты всех доработок проекта, включая небольшие правки. Документ создаётся до реализации и обновляется по мере выполнения; для продолжения одной задачи используется существующий файл.

Имя файла: `YYYY-MM-DD-short-topic.md`. Дата — по часовому поясу Asia/Yerevan. Для разных задач с одинаковой темой в один день добавлять различающий суффикс, не перезаписывая историю.

Для небольшой правки достаточно короткого документа:

```markdown
# Название задачи

Дата: YYYY-MM-DD.

## Требования
- [ ] Ожидаемое поведение и границы изменений.

## Реализация
- [ ] Необходимые изменения.

## Проверка
- [ ] Проверка результата и затронутых существующих сценариев.

## Результат
Что выполнено, ограничения, сообщение коммита.
Публикация: не выполнялась / дата и версия deployment.
```

Большие задачи разбиваются на этапы. Макет, серверная реализация и публикация отмечаются отдельно. Галочки ставятся после проверки, а невыполненные пункты остаются открытыми. В документах не хранятся секреты, коды входа и приватные данные пользователей. Создание коммита и публикация не подразумеваются самим наличием плана.
