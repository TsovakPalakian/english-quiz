## 3. Conversation: диалоги и языковой анализ речи

## 4. Dictionary: словарные данные и точное значение

Вид работы: подключение подготовленного источника, дополнение данных и лицензирование.

WordNet 3.0 импортирован и проверен локально; адаптер и конфигуратор поддерживают его. Production runtime сейчас не передаёт wordnet, а в UI нет зарегистрированного Dictionary.

- ⬜ Подключить нормализованный dataset, закреплённый digest, доступ к данным и явное сопоставление reference/sense; не брать первое значение по написанию.
- ⬜ Передать источник через runtime в конфигуратор и генератор. Регистрация словарного адаптера сама по себе не передаёт evidence в `QuizGenerationContext`.
- ⬜ Определить лицензированные источники недостающих переводов, IPA, форм, сочетаемости и примеров; не обещать, что всё это предоставляет WordNet.
- ⬜ Проверить полисемию, части речи, фразы/идиомы и соответствие определений выбранному значению. CEFR не считать подтверждённым словарным фактом без источника.
- ⬜ Проверить контексты, регистр, допустимые варианты и диалекты; отдельные рубрики для чтения/письма не объявлять готовыми по наличию quiz-review.

Критерий закрытия: словарный ответ и генерация используют подтверждённое значение с происхождением/условиями повторного использования; неоднозначность требует выбора, а не скрытого объединения карточек.

## 5. TTS и автоматический Listen: недостающее соединение сервисов

Вид работы: конкретное недостающее production-подключение, затем акустическая приёмка.

Azure TTS зарегистрирован. Однако `openWorkbenchPreparation` создаёт `QuizGenerationContext({review})` без dataset/resolveReference/media/resolveAudio. Поэтому словарное evidence отсутствует, а `preparation.audio` для Listen остаётся null. Включить TTS в настройках недостаточно для исправления этой цепочки.

- ⬜ Подключить существующие сервисы словарных материалов/эталонного аудио к production-фабрике и подготовке пакета, сохранив source mapping и проверку доступа.
- ⬜ Передавать проверенные `media`/`resolveAudio` и при необходимости dataset/reference dependencies в контекст генерации.
- ⬜ Реально получить разрешённое TTS-аудио, проверить decoder, сохранение происхождения, кеш и отсутствие повторного внешнего вызова при открытии.
- ⬜ Проверить содержание записи, ударения многозначных слов, скорость, голоса en-US/en-GB и естественность.
- ⬜ Сохранить ручную загрузку аудио как отдельный рабочий путь, не требующий автоматического TTS.

Критерий закрытия: автоматический Listen для подходящего слова получает реальный доступный файл; повтор использует кеш; отсутствие/удаление файла даёт отказ, а не готовый квиз. Текст и аудио подтверждает преподаватель.

Опора: `src/learning-workbench-preparation.mjs`, `src/quiz-generation-context.mjs`, `src/quiz-package-generator.mjs`, `src/quiz-language-materials.mjs`.

## 12. AI-видео: последний приоритет
