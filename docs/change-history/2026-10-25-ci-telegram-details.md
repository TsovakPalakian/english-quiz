# Полезные сведения в Telegram CI

🟨 Добавить ветку/тег, тип события, автора запуска, номер запуска и попытки, сохранив коммит и прямую ссылку на Actions.
🟨 При ошибке различать падение тестов, подготовку/job и деплой; при отмене явно сообщать об отмене. Ссылку на сайт показывать только при успешном deploy.
🟨 Использовать только доступные метаданные GitHub и результаты jobs. Не читать логи, не выполнять дополнительные API-запросы, не включать credentials или подписанные URL. Локальный post-commit notifier не менять.
⬜ Пользователь проверяет `npm run check -- --mode=local check-environment`, затем новый CI-запуск. Тесты, commit, push, Telegram-запросы и deploy агентом не выполняются.

## Результат
Формат сообщения обновлён, добавлены регрессионные проверки метаданных, стадий ошибок и отсутствия секретов. Поведение ожидает пользовательского прогона.

Сообщение коммита: `Enriched CI Telegram notifications with run context and failure stages`.
