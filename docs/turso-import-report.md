Аккаунты, роли и пароли не перенесены в Turso: авторизация остаётся в D1.
Одна общая пара использует один профиль и общие определения/ссылки, а не две
копии её состояния. Совпадающие определения внутри одного scope объединены;
личные определения разных учеников не становятся общими автоматически.
Некоторые одинаковые по слову карточки остаются отдельными: это разные
определения или границы приватности, не доказанные дубликаты.

В источнике все списки `learned` пусты. Это не ошибка импорта: ненулевые
записи выученных карточек не придуманы. Один legacy-вариант не удалось
однозначно связать с определением карточки — он сохранён в аудите.

Импорт выполнен 90 небольшими транзакционными пакетами. До завершения
сверки маркер импорта имеет статус `importing`. При обрыве `apply` проверяет
уже сохранённые строки и продолжает только отсутствующие, без перезаписи.
Другой снимок или несовпадающие строки отклоняются. После сверки всех
импортированных полей по контрольным суммам установлен статус `verified`.
Локальная SQLite-копия вместе с индексами занимает 14 864 384 байта
(примерно 14,9 МБ); размер хранения у провайдера отдельно не измерялся.

## Неоднозначности и оставшиеся работы

В `migration_issues` сохранены 12 замечаний, они не являются общим
содержимым уроков и не должны попадать в публичные API:

- 1 ответ в старом общем блоке без владельца: сохранён отдельно, не опубликован.
- 1 запись word-варианта: не выбрана произвольно одна из неоднозначных карточек.
- 3 ссылки настройки доступа на отсутствующие в текущем снимке уроки.
- 3 старых локальных/парных набора квизов: не восстановлены поверх актуального
  `shared/card-quizzes.json`, иначе удалённые квизы могли бы вернуться.
- 3 старых набора cardEdits: не объявлены общими изменениями, поскольку текущий
  сервер при чтении заменяет их общим источником; оригиналы есть в снимке.
- 1 замечание о версии статических каталогов: сохранены локальные файлы,
  соответствие опубликованным assets ещё нужно подтвердить.

Четыре уникальных встроенных изображения тем вынесены из JSON в приватные
файлы снимка (352 649 байт), а в Turso оставлены служебные ссылки
`migration-media:<sha256>`. Для тестового UI требуется их приватная раздача
или отдельное тестовое медиахранилище. Production R2 для этого не изменялся.
Виджет demonstratives сохранён как файл каталога; его код не выполнялся
импортером и не превращён в SQL-данные.

Изолированный локальный API/UI подключён и проверен на временных записях
тестовой Turso (см. отдельный отчёт). Настоящий login и ограниченная интеграция
основного интерфейса подключены локально на 8789, см. [turso-main-interface.md](turso-main-interface.md).
Следующие этапы: живой вход владельца, оставшиеся учебные мутации, разрешение
замечаний, обратный экспорт и финальная дельта. Рабочий
сайт переключать нельзя. При следующем продолжении можно использовать
сохранённый снимок без повторного чтения production.
