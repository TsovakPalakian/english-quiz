# План реализации TASK-5: Карусель предпросмотра файлов и полноразмерный просмотр в Feedback Modal

## Предупреждение о границах изменений и изоляции скоупа
> <span style="color: red; font-weight: bold;">WARNING</span>: Запрещено задевать, модифицировать или ломать функционал, не относящийся к текущей задаче. Изменения строго изолированы модальным окном обратной связи (Feedback Modal) и предпросмотром прикрепленных файлов.

---

## 1. Описание задачи и уточненные требования пользователя
В задаче [TASK-5](https://lumiscia.atlassian.net/browse/TASK-5) реализуется:
1. **Карусель предпросмотра по центру**:
   - Перелистывание вперед и назад (`‹` и `›`) по всем прикрепленным файлам.
   - Текущий файл отображается по центру блока предпросмотра.
   - Внизу блока отображается название файла и аккуратный текстовый счетчик `X / N` без лишних кнопок-плашек.
   - Кнопка удаления текущего файла («✕») в правом верхнем углу.
   - Если прикреплен 1 файл, стрелки навигации скрываются.
2. **Полноразмерный просмотр (Lightbox)**:
   - Клик по самому изображению предпросмотра открывает его вне окна обратной связи — по середине экрана во весь размер с затемнением фона (`lightbox`).
   - Кнопка-плашка `[🔍 Full size · 1 / 3]` полностью убрана из интерфейса.
   - В полноразмерном оверлее доступны стрелки перелистывания (`‹` и `›`), счетчик и закрытие (по кнопке «✕», клику вне изображения или нажатию `Escape`).

## 3. Чеклист этапов реализации

- 🟩 **Шаг 1: Согласование шаблона и логики отображения с пользователем**
  - Описание шаблона карусели с открытием полноразмерного просмотра по клику на изображение.
  - Удаление плашки `[🔍 Full size]`.
  - Описание поведения каждой кнопки, поля и цепочки переходов.
  - Одобрение получено (`одо`).

- 🟩 **Шаг 2: Реализация карусели и центрированного оверлея Lightbox**
  - Интеграция карусели в блок предпросмотра с центрированием изображения.
  - Клик по миниатюре открывает полноразмерный оверлей вне модального окна в центре экрана.
  - Навигация «‹» и «›» и счетчик `X / N`.
  - Сохранение обратной совместимости для селекторов тестов (`#feedbackPreviewBox`, `#feedbackPreviewImg`).

- 🟩 **Шаг 3: Сборка артефактов и автоматическое тестирование**
  - Запуск сборщика ассетов `npm run build:preview`.
  - Запуск UI-тестов модального окна обратной связи `node test/test-feedback-ui.mjs`.
  - Добавление и успешный прогон целевого визуального теста карусели и полноразмерного режима `node test/test-feedback-carousel-visual.mjs`.
