# План автономного захвата скриншотов в тесте студенческой изоляции уроков

## Назначение задачи

Обеспечить автономный захват снимков экрана (`task-student-lesson-view-sky.png`, `task-student-lesson-view-dark.png`, `task-student-lesson-view-sand.png`) в визуальном сценарии Playwright (`test-student-lesson-editor-isolation.mjs`) для гарантированного прохождения тестов на чистых окружениях и в пайплайнах CI без зависимости от предварительно существующих файлов на диске.

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>: Запрещено задевать, модифицировать или ломать функционал, не относящийся к текущей задаче. Выполняемые задачи строго и изолированно должны задевать только свой функционал (автономная генерация снимков экрана в тестовом стенде Playwright без изменения продуктовой логики).
