# Пауза возврата созвездия

Предупреждение: файл фиксирует только тест паузы возврата на гостевом небе. Роли, группы, экзамены, уроки, словарь, рисунок звезд, `chatenc:` и `wrangler.toml` не менять.

## Что сделано

Полный прогон съедал последние 100 мс пятисекундного отсчета живым временем Playwright, и небо успевало сменить созвездие до blur. Уход на 4,9 секунде теперь ставится в том же заходе, что и возврат в окно. Снимок на повторном возврате тоже снимается виртуальным таймером на 4,9 секунде.

## Какой тест запускать

`node --test test/test-constellation-return-pause-ui.mjs`

Environment пустой.

Строка коммита: `Kept the constellation return countdown from expiring before the test leaves the window.`
