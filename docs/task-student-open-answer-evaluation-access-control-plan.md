# План разграничения прав доступа к оцениванию открытых заданий и критериальному рубрикатору (ACCESS-CONTROL-STUDENT-TASK)

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>
> **ПРЕДУПРЕЖДЕНИЕ О НЕПРИКОСНОВЕННОСТИ СТОРОННЕГО ФУНКЦИОНАЛА:**
> Запрещается модифицировать, нарушать или затрагивать логику сторонних модулей (система авторизации, сессии, каталог словаря, карточки слов, квизы, грамматический тренажер, биллинг, группы и профили пользователей). Задачи строго и изолированно затрагивают только компонент отображения открытых заданий (`block.type === 'task'`), ролевое разделение интерфейса ученика и преподавателя, обработчики кнопок оценивания и критериального рубрикатора.

---

## 1. Постановка проблемы и требования

1. **Недопустимость самооценивания учеником**:
   - На странице ученика (`authUser.role === 'USER'` без прав преподавателя) отображались элементы управления учителя: поле ввода `Teacher Evaluation`, кнопки `✓ Approve Grade`, `🤖 Check with AI`, интерактивные кнопки баллов рубрики (`0`, `1`, `2`), кнопка `✓ Save Criteria Grade` и `🤖 AI Rubric Analysis`.
   - Ученик мог самостоятельно выставлять себе баллы, одобрять оценку и сохранять критерии без участия преподавателя.
2. **Оценивание преподавателем только по запросу ученика**:
   - Преподаватель может выставить оценку только в случае, если ученик отправил задание на проверку с помощью кнопки `📩 Send to Teacher for Review` (`teacherReviewRequested = true`).
   - Если ученик еще не запросил проверку, панель оценивания отображает статус ожидания отправки задания учеником, блокируя досрочное выставление оценки.
3. **Режим только для чтения для проверенных заданий**:
   - После выставления оценки преподавателем или ИИ ученик видит подтвержденные результаты строго в информационном режиме (read-only): статический бейдж оценки `Teacher Evaluation: X / Y pts ✓ Verified by Teacher`, статическую таблицу критериев рубрики без кнопок шкал и без кнопок сохранения.

---

## 2. Границы изменений и инварианты (Invariants)

1. **Инвариант прав ученика**:
   - Никакие клики ученика не могут активировать `data-approve-grade`, `data-ai-eval`, `data-rubric-criterion`, `data-save-rubric-grade`, `data-ai-rubric-analysis`.
2. **Инвариант прав учителя**:
   - Преподаватель видит интерактивную панель оценивания только тогда, когда ученик запросил проверку (`block.teacherReviewRequested = true`) либо при проектировании урока преподавателем в собственном аккаунте (`!viewAccount`).
3. **Инвариант отображения**:
   - Для проверенных работ ученик видит официальную оценку и набранные баллы по критериям рубрики без инпутов и кнопок действий.
