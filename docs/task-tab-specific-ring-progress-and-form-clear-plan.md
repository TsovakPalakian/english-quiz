# План реализации: индивидуальный круговой прогресс-бар (Ring Progress) для каждого типа и очистка форм

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>
> **ПРЕДУПРЕЖДЕНИЕ О ЗАТРАГИВАНИИ СМЕЖНОГО ФУНКЦИОНАЛА И НЕПРИКОСНОВЕННОСТИ СИСТЕМЫ:**
> Текущая задача строго изолирована и касается:
> 1. Отказа от принудительного объединения всех источников в единую форму черновика.
> 2. Реализации собственного индивидуального кругового прогресс-бара (`.lm-pdf-ring`) внутри каждой отдельной вкладки генерации (`📁 File / PDF`, `🌐 Web URL`, `📝 Manual Script`, `✨ Complement Current Lesson`).
> 3. Полной и своевременной очистки полей ввода формы (текст `#lmScriptInput`, адрес ссылки `#lmUrlInput`, файл загрузки) при запуске и завершении генерации.
> Запрещено затрагивать, модифицировать или ломать смежный функционал:
> - Извлечение и парсинг текста из файлов PDF, URL или ручного скрипта.
> - Структуру уроков (`lmState.blocks`), D1/R2 схемы хранения и сохранение черновиков.
> - Авторизацию преподавателей и проверку прав доступа.

---

## 1. Точная формулировка задачи (Problem Statement)

1. **Раздельные формы для каждого типа контента**:
   - Отклонен переход к принудительному единому диалогу ревью.
   - Каждая вкладка (`File / PDF`, `Web URL`, `Manual Script`, `Complement Current Lesson`) сохраняет свою собственную форму работы и сценарий взаимодействия.

2. **Индивидуальный круговой прогресс-бар на каждом типе**:
   - На каждой вкладке при запуске генерации отображается свой собственный круговой индикатор с процентами и кольцевой заливкой (`.lm-pdf-ring`), а также динамический список этапов анализа.
   - Индикатор изолирован внутри контейнера своей вкладки (`#lmTabPaneFile`, `#lmTabPaneUrl`, `#lmTabPaneScript`, `#lmTabPaneLesson`), не перекрывает соседние вкладки и не затирает состояние соседа.

3. **Обязательная очистка форм ввода (`форма должна вычищаться`)**:
   - При отправке данных на генерацию или завершении операции форма ввода вычищается:
     - Очищается текстовое поле сценария `#lmScriptInput`.
     - Очищается поле ссылки `#lmUrlInput`.
     - Сбрасывается значение выбранного файла в `[data-lesson-pdf-import-file]`.
     - Блокировка кнопок обновляется в соответствии с пустым вводом.
     - Устаревшие или завершенные блоки прогресса своевременно очищаются.
