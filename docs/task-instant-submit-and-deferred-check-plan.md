# План реализации мгновенной проверки при одиночном выборе и удаления кнопок Check и Submit Answer

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>
> **ПРЕДУПРЕЖДЕНИЕ О НЕПРИКОСНОВЕННОСТИ СТОРОННЕГО ФУНКЦИОНАЛА:**
> Запрещается модифицировать, задевать или нарушать логику модулей, не относящихся к текущей задаче (каталог словаря, грамматический тренажер, расписание, биллинг, профили пользователей, администрирование групп). Задачи строго и изолированно затрагивают только механику фиксации выбора и проверки в интерактивных заданиях с одиночным выбором (Choice, Exercise с выбором, True / False).

---

## 1. Постановка задачи: Пункт 1 — Шаблон карточки задания с одиночным выбором варианта (Choice и True / False) с мгновенной проверкой и удаленными кнопками Check и Submit Answer

1. **Цепочка взаимодействия и элементы интерфейса**:
   - В карточке задания с одиночным выбором ответа (`Task 6` / `Choice Quiz` / `Exercise` с вариантами ответов / `True / False`) студент видит вопрос и список вариантов.
   - В нижней строке действий карточки кнопки `Check` и `Submit Answer` (а также плашка ручной фиксации `✓ Submitted & Locked`) полностью удалены. Отображается исключительно кнопка отправки на проверку учителю `📩 Send to Teacher for Review`, выровненная по правому краю.
   - Студент нажимает на один из вариантов (в качестве образца: вариант `in` в `Task 6`).
   - В момент клика (длительность: мгновенно, 0.05 с):
     - Выбранный вариант получает фокус и визуальное оформление выбранного элемента (`is-selected`).
     - Все варианты ответов немедленно блокируются (`disabled`, `is-locked`), исключая повторный клик или смену решения.
     - Немедленно запускается проверка ответа: отображается плашка вердикта `Correct` (или `Not quite`) и текстовое пояснение правила (`Correct! 'Believe in' is correct.`).
     - Блок получает признак проверенного (`checked = true`, `submitted = true`), начисляется соответствующий балл в общий прогресс урока.
   - Студент может нажать кнопку `📩 Send to Teacher for Review` для отправки уведомления преподавателю в чат важных сообщений.

## 3. Чеклист реализации

- 🟨 **Пункт 1: Шаблон карточки задания с одиночным выбором варианта (Choice и True / False) с мгновенной проверкой и удаленными кнопками Check и Submit Answer**
  - Разметка карточек с одиночным выбором без кнопок `Check` и `Submit Answer`.
  - Блокировка всех вариантов сразу после выбора первого ответа.
  - Мгновенное отображение плашки вердикта (`Correct` / `Not quite`) и пояснения.
  - Размещение кнопки `📩 Send to Teacher for Review` по правому краю строки действий.

- ⬜ **Пункт 2: Функция мгновенной проверки и начисления баллов при выборе одиночного варианта**
  - Обработка клика по варианту (`data-pick`): фиксация выбора, установка `marked`, `correct`, `submitted = true`, `checked = true`.
  - Пересчет баллов и моментальная перерисовка интерфейса с заблокированными радиокнопками.
