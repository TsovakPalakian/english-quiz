# План исправления тестов компоновки созвездий и отрисовки линий

## Назначение задачи
1. Устранить регрессию в тесте интерфейса авторизации (`test-auth-studio-ui`), восстановив контрактную толщину линии созвездий `lineWidth = 0.8` в функции `drawLines`.
2. Устранить регрессию в тесте компоновки созвездий (`test-auth-sky-layouts`), где созвездие Ящерицы (`Lac`) на мобильном вьюпорте 390x844 в режиме регистрации не могло поместиться из-за глобального нижнего отступа. Изолировать расширенные отступы исключительно для созвездия Тельца (`c.abbr === 'Tau'`).
3. Сохранить все визуальные улучшения созвездия Тельца, контрастность линий и позиционирование карточки инспектора.

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>: Запрещено задевать, модифицировать или ломать функционал, не относящийся к текущей задаче. Выполняемые задачи строго и изолированно должны задевать только свой функционал (параметры функции отрисовки линий `drawLines` и границы размещения фигур в функции `fitFigure`).

---

## Чеклист реализации

- 🟩 Создание плана устранения регрессий и изоляции изменений
- 🟩 Восстановление контрактной толщины `lineWidth = 0.8` для линий созвездий в функции `drawLines`
- 🟩 Изоляция расширенных отступов границ в функции `fitFigure` исключительно для созвездия Тельца
- 🟩 Сборка клиентских ассетов (`npm run build:preview` и сборщик ассетов)
- 🟩 Прогон целевых тестов интерфейса и компоновки созвездий
- 🟩 Прогон визуального теста созвездия Тельца

## Этапы выполнения

### Этап 1: Корректировка функции отрисовки линий
В функции `drawLines` модуля сцены звездного неба:
- Восстановить базовую толщину линий созвездий `lineWidth = 0.8` по умолчанию для штатного режима отображения.
- Сохранить улучшенный контрастный цвет `rgba(229,207,152, alpha)` и повышенную толщину `1.8` с мягким свечением только при активной инспекции созвездия.

### Этап 2: Изоляция границ размещения в модуле астрономии
В функции `fitFigure` модуля астрономических вычислений:
- Для созвездия Тельца (`c.abbr === 'Tau'`) сохранить требуемые запасы отступов: `x < 24`, `x > width - 36`, `y < 20`, `y > height - (height > 600 ? 110 : 60)`.
- Для всех остальных созвездий каталога вернуть базовые проверенные границы `x < 18`, `x > width - 18`, `y < 18`, `y > height - 18`, обеспечивающие размещение созвездия Ящерицы (`Lac`) на мобильных экранах.

### Этап 3: Сборка и верификация
- Запустить `npm run build:preview` для генерации сборки.
- Запустить `node --test test/test-auth-studio-ui.mjs`.
- Запустить `node --test test/test-auth-sky-layouts.mjs`.
- Запустить `node --test test/test-taurus-constellation-visual.mjs`.
