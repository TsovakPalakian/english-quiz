# План изоляции экрана уроков от отображения конструктора для роли ученика (USER)

## Назначение задачи

Предотвратить отображение формы создания и редактирования уроков (`#lmEditor`, кнопки `#lmSave` и `#lmPublish`) в учетной записи ученика (`role: USER`) при открытии уроков, обновлении страницы в браузере (F5/Reload) и восстановлении маршрута. Обеспечить гарантированное отображение студенческого режима чтения и выполнения заданий (`#lmPreview`).

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>: Запрещено задевать, модифицировать или ломать функционал, не относящийся к текущей задаче. Выполняемые задачи строго и изолированно должны задевать только свой функционал (изоляция экрана уроков от показа конструктора ученикам без изменения возможностей редактирования уроков для преподавателей и администраторов).

## Чеклист выполнения работ

- 🟩 Этап 1: Статическая разметка шаблона урока — скрыть форму конструктора `#lmEditor` и кнопки учителя `#lmSave`, `#lmPublish` по умолчанию в статической разметке.
- 🟩 Этап 2: Ролевой фильтр и защитные проверки — добавить скрытие `#lmEditor` и кнопок учителя при инициализации роли ученика в функции обновления интерфейса разработчика и профиля.
- 🟩 Этап 3: Контроллер экрана уроков — форсировать `mode = "preview"` и режим `#lmPreview` для пользователей без прав редактирования (`!canEditLessons()`), добавить безопасный вызов форматирования описания при отсутствии объекта стилизации текста.
- 🟩 Этап 4: Сборка клиентских ассетов — пересобрать клиентские скрипты через команду сборки предпросмотра.
- 🟩 Этап 5: Автоматизированные тесты — добавить тесты проверки изоляции экрана уроков для роли ученика при перезагрузке и навигации.
