## Согласовано

🟩 Кружок «100% / Ready to review» и точный список остаются на том баре, с которого шла генерация: File / PDF, Web URL, Manual Script, Complement Current Lesson. Блоки урока остаются на самом уроке.

🟩 При первой генерации пишется подробное описание урока в поле Description, до 2400 знаков. Это описание не единственный источник содержания.

🟩 Для следующих генераций содержание берется из всего урока. Повтор не генерируется.

🟩 Поле Count и подпись Max 30 остаются. Отдельный безлимитный вывод на экран не добавляется.

🟩 Закрепленная полоса «N sections selected / Apply selected sections» убирается.

🟩 В просмотре черновика остается одна пара `Cancel` и `Apply`, сверху. Нижняя пара убирается. Подсказка «Draft preview ready...» остается.

🟩 В Voice Mode заготовки убираются. Ответ идет от провайдера Conversation. Тема берется из открытого урока. Если провайдер не выбран, вместо заготовки видно, что диалог недоступен.

🟩 После генерации поля всех четырех баров очищаются. Текст одного бара в другой не переносится.

🟩 `Save draft` не подсвечивается. Если сохранять нечего, кнопка серая и не нажимается. `Publish` доступен, когда учитель утвердил все, что нужно утвердить.

🟩 В уведомлениях только настоящие факты: занятие на сегодня, материал на сегодня, у преподавателя сданная работа без опубликованной проверки, у ученика опубликованная проверка. Если таких нет, список пустой. Карточка открывает это место. Переключатель только скрывает свой тип. Постоянные тексты про очередь повторения и Version 2.4.0 убираются. Сигнал за 15 минут не обещаем.
