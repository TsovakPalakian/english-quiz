## 1. Описание дефекта и первопричина

- **Проблема**: При запуске `test/test-task-13-home-visual.mjs` возникает ошибка:
  ```text
  AssertionError [ERR_ASSERTION]: Heading must contain student name: Welcome back, Alice! 👋
  at TestContext.<anonymous> (test/test-task-13-home-visual.mjs:92:12)
  ```
- **Первопричина**: В функции отрисовки дашборда `paintHomeDashboard` было внедрено утвержденное требование отображения только первого имени студента (`Welcome back, Alice! 👋` вместо полного имени `Alice Student`). В то же время строка 92 теста `test/test-task-13-home-visual.mjs` сохранила устаревшую проверку `assert.ok(headingText.includes('Alice Student'))`.
