# План устранения дефекта создания пустых правил при генерации уроков

> <span style="color: red; font-weight: bold;">WARNING</span>: Запрещено задевать, модифицировать или ломать функционал, не относящийся к текущей задаче. Выполняемые правки строго изолированы рамками блока правил (`type === 'rule'`), их генерации, отображения в редакторе уроков и предпросмотре для ученика. Смежные модули (словарь, викторины, чат, экзамены) не модифицируются.

---

### Анализ дефекта
1. При импорте/генерации уроков из PDF или скриптов правила (`data.rules`) сопоставляются с каталогом грамматики через `lmPdfGrammarMatch`.
2. При наличии совпадения в `lmPdfDraftBlocks` происходило удаление разметки `delete block.html` и присвоение объекта `match = { grammarRule: title }`. При этом `block.name` и `block.title` не устанавливались, а `explanation`, `pattern` и `examples` не переносились в свойства блока.
3. В редакторе уроков `lmBlockBody` для блоков `type === "rule"` вызывалась только функция `lmRuleCardHtml(block, false)`, которая отображала исключительно кнопку/плашку темы `<div class="g-topic tone-advanced"><b>Rule</b><span class="form">open</span></div>` без полей редактирования и без вывода объяснения и примеров.
4. В генераторе дополнительных заданий `lmEnsureRulesInLesson` блоки создавались со свойствами `title`, `name`, `explanation`, `pattern`, `examples`, но они не отображались ни в редакторе, ни в предпросмотре для студента (`lmPreviewBlock`).

### Чек-лист реализации

- 🟩 **Этап 1: Доработка генерации и нормализации правил в `client/52b-lesson-pdf-import.js`**
  - Сохранение `title`, `name`, `explanation`, `pattern`, `examples` в блоках правил `lmPdfDraftBlocks`.
  - Предотвращение обнуления заголовка и утраты содержания правил.
- 🟩 **Этап 2: Полнофункциональный редактор блока правил в `client/52-lessons.js` (`lmBlockBody`, `lmBlank`, `lmHead`)**
  - Поддержка `type === "rule"` в `lmBlank` с дефолтными полями.
  - Отрисовка полей `Rule title`, `English explanation`, `Structure / Pattern (EN)`, `Examples (English — Russian)` и плашки темы `lmRuleCardHtml`.
  - Двусторонняя синхронизация ввода через `data-field` с сохранением черновика.
- 🟩 **Этап 3: Структурированный предпросмотр правил для студента в `client/52-lessons.js` (`lmPreviewBlock`)**
  - Отрисовка обучающей карточки правила с плашкой грамматики, заголовком `<h3>`, объяснением, блоком `Pattern: <code>` и списком примеров `<ul><li>`.
- 🟩 **Этап 4: Сборка ассетов и тестирование**
  - Сборка `npm run build:preview`.
  - Запуск целевых тестов `test/test-lesson-pdf-enrichment.mjs`, `test/test-lesson-pdf-draft.mjs` и новых тестов `test/test-lesson-rule-blocks.mjs`, `test/test-lesson-rule-blocks-ui.mjs` (32/32 pass).
