## 1. Постановка задачи и требования пользователя (Jira TASK-7)

1. **Passkeys (Ключи доступа)**:
   - Все элементы управления ключами доступа вынести под кнопку с названием `Set passkeys`.
   - При повторном нажатии на кнопку содержимое блока должно скрываться (поведение аккордеона / toggle).
   - Поле ввода `Passkey name`: убрать значение по умолчанию `My device`, добавить плейсхолдер `Set device name` серого цвета (`var(--mute)`) и сделать ввод имени обязательным (`required`).
   - Кнопку `Add passkey` отображать только после нажатия на кнопку `Send confirmation code`.
   - Кнопка `Add passkey` должна становиться активной (`disabled = false`) только после ввода пользователем 6-значного кода подтверждения.

2. **Active sessions (Активные сессии)**:
   - Скрыть блок активных сессий и истории входов под кнопку с названием `Show active sessions`.
   - При повторном нажатии на кнопку содержимое блока скрывается.
   - Для ролей учеников и учителей скрыть блок технических сетевых подробностей `Connection details`.

3. **User (Профиль пользователя)**:
   - В боковом меню настроек под именем пользователя удалить вывод технического названия роли (`User/Admin/Developer`).

4. **Change password (Смена пароля)**:
   - Кнопка `Change password` должна работать как переключатель: при первом нажатии форма открывается, при втором — скрывается.
   - Сделать форму изменения пароля компактной (уменьшенные отступы, компактные поля ввода и кнопка сохранения).
