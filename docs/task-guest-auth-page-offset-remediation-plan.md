# План устранения дефекта вертикального смещения страницы при переходе к авторизации

## Назначение задачи
1. Устранить критический дефект вертикального сдвига страницы вниз на 100% высоты области просмотра (`100dvh`) при переходе со стартового экрана (`home`) к форме авторизации (`account`) по клику на кнопку «Enter the Learning Studio».
2. Восстановить правильную иерархию DOM-дерева в разметке главной страницы: удалить лишний непарный закрывающий тег `</div>` в секции `#home` после блока дашборда, из-за которого глобальный контейнер страницы (`wrap`) преждевременно закрывался.
3. Гарантировать нахождение секции авторизации (`account`) внутри общего контейнера (`wrap`), обеспечивая идеальное вертикальное и горизонтальное центрирование формы логина на экране без образования паразитного пустого пространства над ней.
4. Проверить корректность перехода на экранах во всех темах (`sky`, `dark`, `sage`).

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>: Запрещено задевать, модифицировать или ломать функционал, не относящийся к текущей задаче. Выполняемые задачи строго и изолированно должны задевать только свой функционал (парность тегов разметки главной страницы, контейнерная иерархия секций `home` и `account`, штатное отображение формы авторизации).

## Этапы выполнения

### Этап 1: Исправление баланса тегов в разметке
- В файле разметки в конце секции `#home` удалить ошибочный закрывающий тег `</div>`, добавленный после `#homeDashboard`.
- Обеспечить закрытие секции `#home` непосредственно перед началом секции `#cardstat` без нарушения родительского контейнера `.wrap`.

### Этап 2: Верификация дерева элементов
- Проверить с помощью DOM-анализатора, что родительским элементом для `#home` и `#account` является `.wrap`.
- Убедиться, что при переключении класса `.guest-auth` секция `#account` размещается по центру видимого экрана.

### Этап 3: Тестирование
- Запустить целевые тесты переключения экранов и визуальной центровки формы авторизации.
