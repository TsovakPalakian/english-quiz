## 1. Постановка проблемы и анализ причин

1. **Карточки внутри аккордеона отображаются развернутыми**:
   - В логике рендеринга одиночного блока флаг `isShut` вычислялся как `isVerifiedSection ? (block.collapsed !== false) : Boolean(block.collapsed)`.
   - В сохраненных уроках и шаблонах создания новых блоков свойство `collapsed` по умолчанию уже инициализировано значением `false`.
   - Из-за этого выражение `block.collapsed !== false` (`false !== false`) вычисляется в `false`, и все проверенные карточки внутри раскрытого аккордеона рендерились полностью открытыми (развернутыми), перегружая интерфейс.
   - **Решение**: Для проверенных блоков в аккордеоне карточка должна быть свернута по умолчанию (`isShut = true`), пока пользователь явно не раскрыл её нажатием на стрелку сворачивания (`expanded === true`).

2. **Отображение слов в свернутом виде карточек**:
   - В свернутом состоянии карточки строка предпросмотра (`.lm-summary`) имела невыразительный приглушенный серый цвет (`color: var(--lm-mute)`), обычную толщину шрифта (`font-weight: normal`) и мелкий размер (`font-size: 14px`).
   - Из-за этого слова и заголовки свернутых карточек трудно читаются при быстром просмотре списка заданий.
   - **Решение**: Для свернутых карточек (`.lm-block.is-shut .lm-summary`) задать жирное начертание (`font-weight: 700`), увеличить размер шрифта до `16px`, установить контрастный цвет темы (`color: var(--lm-ink)`), сохранив адаптивность под все темы оформления.

## 3. Этапы реализации и чеклист

- 🟨 **Этап 1: Документирование, подготовка макетов и согласование**
  - 🟩 Зафиксировать план и защитный блок в `docs/task-verified-cards-collapse-and-bold-words-plan.md`.
  - 🟩 Сгенерировать визуальные макеты в темах Sky, Dark и Sand.
  - 🟨 Согласовать реализацию с пользователем.

- ⬜ **Этап 2: Реализация логики сворачивания проверенных карточек**
  - ⬜ Обеспечить состояние по умолчанию `isShut = true` для карточек внутри проверенного аккордеона (`isVerifiedSection === true`), если карточка не была явно раскрыта пользователем (`block.expanded !== true`).
  - ⬜ Настроить переключение сворачивания/разворачивания по кнопке `data-lm-fold` для проверенных карточек с сохранением консистентности.
  - ⬜ При редактировании карточки (`data-lm-edit`) раскрывать ее содержимое.

- ⬜ **Этап 3: Стилизация превью свернутых карточек**
  - ⬜ В стилях `.lm-block.is-shut .lm-summary` задать жирный шрифт (`font-weight: 700`), кегль `16px` и цвет `var(--lm-ink)`.
  - ⬜ Обеспечить кросс-темовую поддержку без хардкода цветов (Sky, Dark, Sand).

- ⬜ **Этап 4: Тестирование и сборка ассетов**
  - ⬜ Обновить целевые тесты в `test/test-lesson-verified-accordion-tabs.mjs` для проверки сворачивания проверенных карточек и нового стиля текста превью.
  - ⬜ Выполнить `npm run build:preview`.
  - ⬜ Выполнить сборку продакшен-ассетов `node ops/build-learning-production-assets.mjs`.
  - ⬜ Запустить целевые тесты и убедиться в успешном прохождении.
