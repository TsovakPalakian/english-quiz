# План реализации: Окно управления чатом и адаптивный свернутый овальчик

## Описание задачи
1. Добавление кнопок управления окном в верхний левый угол навигационной панели чата (`.chat-rail`):
   - Кнопка «Закрыть» (✕, красный акцент);
   - Кнопка «Свернуть» (─, желтый/янтарный акцент);
   - Кнопка «Развернуть / Компактный вид» (⤢, зеленый акцент).
2. Стилизация кнопок: квадратные плашки 16x16px со скруглением `border-radius: 4px`, тонкой полупрозрачной рамкой `rgba(..., 0.22)` и заливкой `rgba(..., 0.08)`, компактными центрированными векторными символами 8x8px с внутренним отступом 3.5px.
3. Иерархия состояний окна чата:
   - **Состояние 1 (Полное окно)**: полноразмерный чат со списками контактов, комнат и настроек;
   - **Состояние 2 (Компактное окно)**: плавающее окно 360x480px в нижнем правом углу с минимальным набором инструментов (заголовок с 3 кнопками управления, лента сообщений, строка ввода);
   - **Состояние 3 (Свернутый виджет в левом нижнем углу)**:
     - *Если место есть*: горизонтальная капсула шириной 240px с аватаром преподавателя, именем, статусом диалога, кнопками разворачивания и закрытия;
     - *Если места нет / перекрывает поле*: компактный овальчик шириной 92px с аватаром и кнопками разворачивания и закрытия (текстовый блок скрывается для освобождения поля ввода под ним).
   - **Состояние 4 (Закрыто)**: виджет и окно полностью скрыты.

Запрещено затрагивать логику отправки сообщений, криптографию WebAuthn, протокол синхронизации WebSocket, структуру Durable Objects, карточки слов и грамматику. Все изменения вносятся изолированно в разметку элементов управления окном чата, стили окна и виджета, а также контроллер переключения состояний и детектор перекрытия полей ввода.

## Чек-лист реализации

- 🟩 **Этап 1**: Создание документации задачи и сохранение утвержденных скриншотов в docs/
- 🟩 **Этап 2**: Разметка кнопок управления окном и виджета свернутого состояния в `production/chat.html`
- 🟩 **Этап 3**: CSS-стили для кнопок окна, компактного плавающего окна 360x480px, полной капсулы и компактного овальчика 92px в `production/chat.css`

- 🟩 **Этап 5**: Пересборка клиентских и продакшн ассетов (`npm run build:preview`, `node ops/build-learning-production-assets.mjs`)
- 🟩 **Этап 6**: Создание и запуск тестов для проверки всех состояний и переходов в `test/test-chat-adaptive-dock.mjs`
