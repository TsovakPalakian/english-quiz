## 1. Точная формулировка проблемы (Problem Statement)

1. **Схлопывание пробелов и слияние слов фразы**:
   - В функции `paintHangman` вся строка ответа разбивалась посимвольно методом `.split("")` и объединялась обратно через одинарный пробел `.join(" ")`.
   - Пробел между словами возвращался как один символ пробела. При объединении через `.join(" ")` на стыке слов возникали пробелы, которые парсер HTML по умолчанию схлопывал до одного стандартного пробела шириной в 1 знак.
   - Из-за этого расстояние между буквами одного слова (разделенными пробелом из-за `.join(" ")`) и расстояние между словами фразы оказывалось абсолютно одинаковым, создавая эффект слитного написания фразы: `talktoyo_rself`.

## 2. Границы области изменений и инварианты (Scope Boundaries & Invariants)

- **Область изменений**:
  - Логика функции отрисовки `paintHangman(item)`: разбиение ответа на слова по пробелам `split(/\s+/)`, посимвольное формирование букв каждого слова и оборачивание слов в строчные блоки с отступом справа (`margin-right: 24px`), исключающим слияние слов.
  
- **Инварианты**:
  - Сохранение правил подсветки угаданных и неугаданных символов (`item.got[ch]`).
  - Сохранение работы кнопок алфавита и подсчета ошибок.
  - Поддержка тем Sky, Dark, Sand через системные переменные палитры.
