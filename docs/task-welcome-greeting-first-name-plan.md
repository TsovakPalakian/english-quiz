# План изменения приветствия на главном экране (Welcome Greeting First Name Only)

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>
> **ПРЕДУПРЕЖДЕНИЕ О НЕПРИКОСНОВЕННОСТИ СТОРОННЕГО ФУНКЦИОНАЛА:**
> Запрещается модифицировать, перемещать или нарушать логику любых несвязанных модулей приложения (каталоги слов, грамматический тренажёр, караоке, администрирование групп, экзамены, воркбенч, профили пользователей, настройки и чат). Правки строго и изолированно затрагивают исключительно отображение имени студента в приветственном блоке на домашнем дашборде.

---

## 1. Постановка задачи и требования

1. **Отображение только имени**: в приветствии на главном экране (`homeWelcomeHeading` / `homeStudentName`) вместо полного имени и фамилии (`Tsovak Palakian`) отображать строго только имя (`Tsovak`).
2. **Безопасная обработка имени**:
   - Извлечение первого слова из полного имени пользователя (`authUser.name`, `authUser.username`), очищенного от крайних пробелов.
   - Корректный фоллбек на `'Student'` при отсутствии данных авторизованного пользователя.
   - Экранирование через `esc(...)` во избежание XSS.
3. **Сохранение адаптивности и тем оформления**:
   - Проверка в основной теме `data-theme="sky"`.
   - Проверка в темной теме `data-theme="dark"`.
   - Проверка в альтернативной светлой теме `data-theme="peach"`.

## 3. Чек-лист реализации

- 🟩 **Этап 1: Доработка функции отрисовки приветствия дашборда**
  - Получение первого слова из имени пользователя (`firstName = String(rawName).trim().split(/\s+/)[0] || 'Student'`).
  - Применение первого имени к элементу `#homeStudentName` и в заголовке `#homeWelcomeHeading`.
  
- 🟩 **Этап 2: Добавление модульных и визуальных тестов**
  - Добавление проверки в тестовый набор, подтверждающей, что для составных имен (`Tsovak Palakian`, `Alice Smith`) в заголовке и span выводится строго первое имя (`Tsovak`, `Alice`).
  - Создание Playwright визуального теста проверки заголовка в темах `sky`, `dark` и `peach`.

- 🟩 **Этап 3: Сборка и верификация ассетов**
  - Сборка скриптов через `npm run build:preview` и генерация продакшен ассетов.
  - Успешный запуск всех целевых тестов.
