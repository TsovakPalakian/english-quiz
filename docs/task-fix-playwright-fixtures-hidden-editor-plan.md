# План исправления тестовых стендов Playwright при скрытом по умолчанию конструкторе уроков

## Назначение задачи

Обеспечить корректное выполнение изолированных визуальных и интеграционных тестов Playwright (`test-lesson-complement-generation.mjs`, `test-manual-script-ai-agent.mjs`, `test-voice-mode-tutor-examiner.mjs`) после внедрения статического атрибута `hidden` на контейнере конструктора уроков (`#lmEditor`) для изоляции роли ученика (`role: USER`).

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>: Запрещено задевать, модифицировать или ломать функционал, не относящийся к текущей задаче. Выполняемые задачи строго и изолированно должны задевать только свой функционал (коррекция стендов инициализации Playwright без нарушения изоляции экрана уроков для учеников и без изменения логики продуктового кода).
