# План устранения таймаута в автоматизированном тесте интерфейса блоков правил

## Назначение задачи
Устранить падение теста при заполнении поля ввода названия правила (`page.fill: Timeout 30000ms exceeded: element is not visible`) в окружении непрерывной интеграции (CI).

### Анализ первопричины
1. **Асинхронная инициализация профиля**:
   - При загрузке страницы в браузере запускается функция инициализации аккаунта, выполняющая сетевой запрос к эндпоинту данных текущего пользователя.
   - В тестовом сценарии отсутствовал перехват этого системного маршрута, из-за чего локальный сервер возвращал код ошибки 404.
2. **Сброс активного экрана в окружении CI**:
   - При получении ответа об отсутствии авторизованного пользователя процедура сброса сессии переключает активный раздел приложения на домашний экран.
   - При переключении экрана контейнер урока скрывается (получает стилевое правило скрытия).
3. **Таймаут действия `page.fill`**:
   - Метод `page.fill` требует, чтобы целевой элемент был физически видим на экране.
   - Поскольку родительский контейнер урока оказывается скрыт фоновым сбросом сессии, действие ожидает видимости элемента до истечения таймаута в 30 секунд.

Запрещено модифицировать хранилище словаря, серверные маршруты авторизации, клиентские стили или сторонние тестовые файлы.

## Чеклист реализации

- 🟩 Этап 1: Добавление изолированного перехвата маршрутов профиля в тестовый сценарий (возврат авторизованного преподавателя со статусом 200)
- 🟩 Этап 2: Фиксация сессионного состояния раздела урока для предотвращения перехода на домашний экран
- 🟩 Этап 3: Явное ожидание видимости контейнера урока и поля ввода перед выполнением действия
- 🟩 Этап 4: Локальный прогон теста и верификация стабильности при параллельном запуске
