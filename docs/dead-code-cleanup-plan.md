# План очистки проекта от неиспользуемого и устаревшего («мусорного») кода

## 1. Описание задачи
В ходе детального аудита кодовой базы (`client/`, `site/`, `src/`) был обнаружен устаревший и мертвый код, оставшийся от ранних прототипов, а также рудименты старого всплывающего меню `#shellSettings`, которое потеряло актуальность после перевода настроек в полноценную страницу `<section id="settings">`.

Цель: безопасно удалить выявленный мертвый код без изменения внешнего интерфейса, поведения приложения и с сохранением прохождения 100% тестов (165 скриптов `ops/check-all.mjs`).
