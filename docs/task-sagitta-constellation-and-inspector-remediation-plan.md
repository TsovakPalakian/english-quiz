# План устранения коллизии карточки инспектора созвездия и оптимизации отображения

## Назначение задачи
1. Устранить наезд карточки инспектора созвездия (`auth-sky-con-inspector`) на звезды и соединительные линии созвездия Стрелы (`Sagitta`), обеспечив ее гарантированное безопасное позиционирование в свободной зоне ночного неба.
2. Исправить алгоритм вычисления штрафов пересечения с линиями (`hitsLine`): обеспечить сопоставление звёзд по их строковым идентификаторам (`id`), чтобы пересечение ребер фигуры созвездия с прямоугольником карточки надежно выявлялось и исключалось через блокирующий штраф.
3. Интегрировать учет общего габаритного прямоугольника созвездия (`figureBox`) в функцию оценки позиций (`score`), отдавая строгий приоритет свободным зонам за пределами контура созвездия.
4. Расширить набор кандидатов размещения карточки свободными зонами по сторонам от фигуры созвездия.
5. Подавить нативный браузерный тултип `Sagitta`, всплывающий поверх карточки инспектора при наведении на интерактивный заголовок созвездия.
6. Устранить тавтологию `Family: Hercules Family`, нормализовав вывод семейства созвездий без дублирования префикса.

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>: Запрещено задевать, модифицировать или ломать функционал, не относящийся к текущей задаче. Выполняемые задачи строго и изолированно должны задевать только свой функционал (алгоритм позиционирования карточки инспектора созвездий, проверка пересечений с линиями и звёздами, подавление нативного тултипа заголовка и форматирование семейств в каталоге/карточке).

## Этапы выполнения

### Этап 1: Коррекция функции сопоставления линий
- Создать карту соответствия строковых идентификаторов звёзд (`c.stars[k].id`) и актуальных координат слотов (`slots[k]`).
- В проверке `hitsLine` извлекать начальную и конечную вершины ребра `[id1, id2]` по их идентификаторам.
- При наличии пересечения отрезка с прямоугольником карточки (`astro.segmentHitsBox(a, b, box)`) назначать блокирующий штраф `+3 000 000`.

### Этап 2: Оптимизация алгоритма размещения и учет figureBox
- Использовать `figureBox` в оценке кандидатов: если кандидат пересекает общий габаритный прямоугольник созвездия, начислять дополнительный штраф.
- Добавить в массив кандидатов позиции слева (`figureBox.left - cardW - 16`) и справа (`figureBox.right + 16`), а также сверху над заголовком созвездия.

### Этап 3: Подавление нативного тултипа
- Для элемента интерактивного заголовка созвездия (`auth-sky-title`) не устанавливать атрибут `title` (или очищать его), чтобы браузер не выводил системный черный тултип поверх карточки.

### Этап 4: Нормализация семейства созвездия
- Если поле `c.family` уже содержит слово `Family`, выводить его как есть (`c.family`), иначе предварять префиксом `'Family: ' + c.family`.

### Этап 5: Верификация
- Запуск сборки `npm run build:preview`.
- Прогон целевых тестов ночного неба и проверка отсутствия наложения карточки на линии и звёзды созвездия Sagitta.
