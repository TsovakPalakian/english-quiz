## 1. Точная постановка проблемы на основе дефекта [TASK-13](https://lumiscia.atlassian.net/browse/TASK-13)

1. **Визуал и контрастность тем оформления (Скриншот 1, Скриншот 2)**:
   - В теме оформления **Cocoa** (`[data-theme="cocoa"]`) вторичные серые надписи (`var(--saas-text-muted)`) и акцентные индикаторы (красный `#ef4444`, синий `#0ea5e9`) имеют недостаточный коэффициент контрастности на коричневом фоне карточек.
   - В пестрой теме **Van Gogh** (`[data-theme="almond"]`) фоновый рисунок просвечивает, и мелкий шрифт теряет читаемость.
   - Требуется внедрить CSS-переменные с авто-коррекцией яркости шрифтов для темных тем и добавить карточкам дашборда мягкое размытие подложки (`backdrop-filter: blur(...)`).

2. **Боковое меню и дублирование прогресса**:
   - В [site/preview.html#L37](file:///Users/tsovakpalakian/PycharmProjects/english-quiz/site/preview.html#L37) и [client/57a-dashboard.js#L121](file:///Users/tsovakpalakian/PycharmProjects/english-quiz/client/57a-dashboard.js#L121) блок `.shell-progress` отображается в сайдбаре даже тогда, когда ученик находится на экране `#home`, где по центру уже показан крупный виджет с аналогичным счетчиком карточек.
   - При `0%` прогресса в центральном блоке кнопка называется `Start studying`, а в боковом меню — `Continue studying`. Логика должна быть унифицирована: при 0% везде отображается `Start studying`.

3. **Навигация и целевые переходы (Скриншот 3, Скриншот 4)**:
   - Кнопка `Start studying` в центральном блоке [site/preview.html#L72](file:///Users/tsovakpalakian/PycharmProjects/english-quiz/site/preview.html#L72) сейчас выполняет `data-jump="groups"` / `data-jump="days"`, перенаправляя на общий список уроков вместо прямого открытия следующего неизученного урока.
   - Плитка `Next lesson` при отсутствии назначенного урока (`—`) кликабельна и ведет на список уроков. Клик должен быть деактивирован (`pointer-events: none` / `disabled`) при пустом значении.

   - Кнопки `Groups` и `Open group` дублируют переход; требуется структурировать действие входа в группу и перехода к списку.

4. **Иерархия блоков и пользовательский опыт**:
   - Заголовок `Welcome back` и технический подзаголовок `Classes are organized in groups` обезличены; требуется добавить обращение по имени (`authUser.name`) и мотивирующую фразу.
   - Блок `Your group` и `Next lesson` должны занимать приоритетное визуальное положение над второстепенными блоками.
   - Виджет `Daily 5-Min Warmup` в состоянии пустого списка (`All caught up! 🎉`) занимает избыточное вертикальное пространство; требуется компактное сворачивание при отсутствии карточек для повторения.

## 3. Математическая модель ступеней мастерства (Tiered Mastery) и ачивок

1. **5 ступеней мастерства и бейджи**:
   - **80% — 🥉 Bronze (Solid Pass)**: базовый зачет, открывает следующий урок. Ачивка: `Solid Ground`.
   - **85% — 🥈 Silver (Confident)**: уверенное владение материалом. Ачивка: `Confident Speaker`.
   - **90% — 🥇 Gold (Mastery)**: золотой стандарт глубокого знания. Ачивка: `Gold Master`.
   - **95% — 💎 Platinum (Expert)**: платиновый уровень эксперта. Ачивка: `Platinum Scholar`.
   - **100% — 👑 Diamond (Perfection)**: абсолютная безупречность без помарок. Ачивка: `Flawless Perfection`.

2. **Персональная целевая планка ученика**:
   - Ученик может сам выбрать свой целевой порог (по умолчанию 80% для свободного продвижения вперед).
   - Преодоление 80% не блокирует продвижение, а дает выбор: идти к следующему уроку либо добить текущий до более высокого бейджа.

3. **Адаптивный риск-ориентированный интерливинг (Формула 50 / 25 / 25)**:
   - **50% вопросов** — целевые пробелы текущего урока (активный ввод без подсказок).
   - **25% вопросов** — контроль текущего урока.
   - **25% вопросов** — глубокие риск-якоря из прошлых уроков курса по формуле уязвимости (давность $\times$ ошибки / стабильность FSRS).

4. **Защитные барьеры**:
   - **Асимметрия доверия**: ошибка в контрольном слове приводит к сбросу статуса и откату балла урока назад.
   - **Толерантность к опечаткам (Typo-Tolerance)**: расстояние Левенштейна = 1 при длине $\ge 6$ символов прощается с запросом перенабора.
   - **Защита от тильта и лимит усталости**: не более 3 спринтов по уроку в день, стоп-пауза при 3 ошибках подряд.
