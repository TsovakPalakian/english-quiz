# План доработки компактного окна чата (chat-mini-window)

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>
> **ПРЕДУПРЕЖДЕНИЕ О ЗАТРАГИВАНИИ СМЕЖНОГО ФУНКЦИОНАЛА И НЕПРИКОСНОВЕННОСТИ СИСТЕМЫ:**
> Текущая задача строго изолирована и касается исключительно функционала компактного окна сообщений (`#chatMiniWindow`):
> 1. Возможности свободного перемещения окна по экрану за шапку (`chat-mini-head`).
> 2. Работоспособности кнопки прикрепления файла (`Attach file`).
> 3. Многострочного поля ввода (`textarea`) с расширением поля и увеличением длины окна вниз при переполнении текста.
> 4. Унификации отправки сообщений (клавиша `Enter`, комбинация `Shift + Enter`, лимит 4000 символов, отправка вложений).
> 5. Приведения расположения и состава кнопок панели ввода к виду расширенного экрана сообщений.
> Запрещено затрагивать, модифицировать или нарушать смежный функционал:
> - Полноэкранный интерфейс сообщений и список диалогов.
> - Механизмы авторизации, WebSocket-соединение и протокол передачи данных.
> - Другие разделы приложения и экраны обучения.
