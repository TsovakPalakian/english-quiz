## 1. Точная формулировка задачи (Problem Statement)

1. **Отсутствие генерации карточек для фраз урока**:
   - В текущей реализации функции [extractFocusQuestionsFromLesson()](file:///Users/tsovakpalakian/PycharmProjects/english-quiz/client/52c-focus-player.js#L14-L69) обрабатываются только блоки `b.tab === 'words'`, `b.type === 'quiz'` и `b.type === 'exercise'`.
   - Блоки фраз `type: "phrase"` ([lmEnsurePhrasesInLesson#L3277-L3278](file:///Users/tsovakpalakian/PycharmProjects/english-quiz/client/52-lessons.js#L3277-L3278)) не извлекаются, поэтому фразы урока полностью отсутствуют в практике Focus Mode.
   - Требуется реализовать извлечение карточек для `b.type === "phrase"` с вопросом на знание значения фразы и вариантами ответа.

2. **Отсутствие селектора области практики (Scope Selector)**:
   - В текущей реализации клик по кнопке `#lmFocusPlayerBtn` ([lmChrome#L1451](file:///Users/tsovakpalakian/PycharmProjects/english-quiz/client/52-lessons.js#L1451)) сразу открывает все доступные задания урока без возможности выбрать фокус.
   - Требуется внедрить выбор из 4 режимов:
     1. `Words & Phrases`: объединение словарного запаса и фраз.
     2. `Classwork & Homework`: объединение классных и домашних заданий.
     3. `Single Category`: изоляция одного конкретного раздела (`Words`, `Phrases`, `Classwork`, `Homework`).
     4. `All Together`: объединение всех материалов урока.

## 2. Границы области изменений и инварианты (Scope Boundaries & Invariants)

- **Инварианты**:
  - Все цвета и оформление берутся строго из CSS-переменных активной темы (`--bg`, `--card`, `--ink`, `--mute`, `--line`, `--acc`, `--acc-s`, `--ok`, `--bad`). Никаких жестко закодированных HEX-значений в новом CSS.
  - Сохранение полной обратной совместимости API функции `openFocusPlayer(customQuestions)`.
  - Сохранение горячих клавиш `1-4`, `Enter`, `Esc`, `ArrowLeft`, `ArrowRight`.
  - Порог 90% и адаптивная отработка ошибок сохраняются в полной мере.
