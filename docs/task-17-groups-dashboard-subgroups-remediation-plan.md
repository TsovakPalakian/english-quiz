> [!WARNING]
> **Строго запрещено затрагивать или изменять функциональность, не относящуюся к текущей задаче.** Все изменения изолированы разделом групп (`#groups`), карточками уровней и отображением списка подгрупп. Запрещено модифицировать логику экзаменов, словарь, грамматику, права доступа и общие контракты API.

## 1. Зафиксированный скоуп задачи

По согласованию с пользователем:

### Отклонённые пункты (не реализуются):
- **Пункт 2.a (Валидация уникальности названий групп):** **ОТКЛОНЁН** — ограничения на повторяющиеся названия групп не вводятся.
- **Пункт 2.c (Слепые зоны клика / верстка иконок):** **ОТКЛОНЁН** — верстка и отступы блока иконок действий (`.day-tools`) остаются без изменений как отдельный независимый тулбар справа от кнопки.

### Утверждённый скоуп реализации:
1. **Пункт 1.a (Динамическая плюрализация на дашборде Groups):**
   - Файл `client/52-lessons.js` (`metricPairs`).
   - При значении `1` выводить форму единственного числа (`Group · 1`, `Student · 1`, `Lesson · 1`), при значениях `0` или `> 1` — форму множественного числа (`Groups · 4`, `Students · 0`, `Lessons · 0`).
2. **Пункт 1.b (Строчный регистр текста / типографика):**
   - Лейблы метрик переводятся в Title Case (`Groups`/`Group`, `Students`/`Student`, `Lessons`/`Lesson`).
3. **Пункт 1.c (Сетка карточек уровней):**
   - Файл `site/preview.css` и `client/52-lessons.js`.
   - Выравнивание 3 метрик в одну симметричную горизонтальную строку без несимметричного переноса третьей метрики.
4. **Пункт 1.d (Индикатор кликабельности на карточках уровней):**
   - Добавление шеврона перехода `›` в правом верхнем углу карточки уровня и интерактивного hover-эффекта.
5. **Пункт 2.b (Управление сортировкой подгрупп):**
   - Файлы `site/preview.html` и `client/52-lessons.js`.
   - В блок `#groupControls` рядом с `#groupSearch` добавить селектор сортировки `#groupSort` (`Newest first` [по умолчанию], `Oldest first`, `Name (A–Z)`, `Name (Z–A)`).
6. **Пункт 2.d (Компоновка карточек подгрупп):**
   - Файл `site/preview.css` и `client/52-lessons.js`.
   - Кнопка группы `button.day` сохраняет собственную границу. Внутри кнопки группы устраняется пустое пространство: блок метрик размещается компактно непосредственно под названием группы рядом с плашкой даты. Тулбар действий (`.day-tools`) остаётся полностью снаружи справа.
