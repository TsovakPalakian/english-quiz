# План реализации: сквозной прогресс-бар во всех вкладках генерации, режим дополнения урока, семантика URL, Script, кнопка Undo и лимит 30 упражнений

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>
> **ПРЕДУПРЕЖДЕНИЕ О НЕПРИКОСНОВЕННОСТИ СИСТЕМЫ И ИЗОЛЯЦИИ ИЗМЕНЕНИЙ:**
> Данные доработки строго ограничены функционалом генератора уроков во всех четырех вкладках (`📁 File / PDF`, `🌐 Web URL`, `📝 Manual Script`, `✨ Complement Current Lesson`), механикой отмены генерации (`Undo`), добавлением сгенерированного контента в секции (`Homework` / `Classwork` / `Words`) и сквозной индикацией прогресса:
> 1. Сквозной визуальный интерактивный прогресс-бар во всех вкладках, где происходит генерация (`File / PDF`, `Web URL`, `Manual Script`, `Complement Current Lesson`), с процентами, описанием шага и блокировкой кнопки со спиннером.
> 2. Разделение логики: если урок уже открыт и имеет заданную тему и блоки, генерация во всех вкладках работает в режиме **дополнения (Complement Mode)**, создавая дополнительный материал по теме урока без затирания или дублирования существующих блоков. Если урока нет — создается новый урок с нуля.
> 3. Семантический анализ во вкладке `🌐 Web URL`: извлечение смысла темы, понятий и лексики из URL и страницы (а не только заголовка и не шаблонная проверка одного слова).
> 4. Доработка вкладки `📝 Manual Script`: генерация дополнительного контента по теме и ключевым словам без вывода того, что уже было в уроке.
> 5. Добавление кнопки мгновенной отмены генерации (`↩ Undo Generation`): удаление всех блоков, добавленных во время последней генерации, и возврат урока к исходному состоянию до запуска.
> 6. Автоматическое добавление новых слов из сгенерированных заданий во вкладку `Words` урока (карточки `wordcard`).
> 7. Установка лимита до 30 упражнений за раз (`max="30"`, скрытие стрелок вверх/вниз в CSS, динамический счетчик `(Total: X tasks)` и распределение по выбранным типам квизов).
> Запрещено затрагивать авторизацию, D1/R2 схемы хранения уроков, плееры экзаменов и тестов.

## 1. Точная формулировка требований

1. **Сквозной прогресс-бар во всех вкладках генерации**:
   - В каждой из четырех вкладок (`File / PDF`, `Web URL`, `Manual Script`, `Complement Current Lesson`) при запуске генерации отображается визуальный интерактивный контейнер прогресса с анимированной полосой, процентом выполнения и описанием текущего этапа.
   - Кнопка действия в активной вкладке блокируется (`disabled`) со спиннером (`Generating...`) для предотвращения повторных запросов.
   - По завершении прогресс-бар достигает 100%, отображается статус успеха и разблокируется управление.

2. **Разделение сценариев: «Новый урок» vs «Существующий урок»**:
   - **Если урока нет (создание с нуля)**: `File / PDF`, `Web URL`, `Manual Script` создают новую структуру урока (заголовок, базовый словарь, грамматику, вводную практику).
   - **Если урок уже открыт (есть тема, словарь и блоки)**: все вкладки переключаются в режим **дополнения (Complement Mode)**: существующие 26 блоков сохраняются без затирания. Создается **дополнительный тематический материал** (новые связанные слова, фразовые связки, новые упражнения: Match, Gap, Choice).

3. **Семантический анализ во вкладке `🌐 Web URL`**:
   - Семантический разбор URL, slug и мета-описания для определения тематики ресурса.
   - Если урок открыт, найденный материал используется для формирования дополнительных заданий и лексики без затирания структуры урока.

4. **Вкладка `📝 Manual Script`**:
   - При наличии активного урока текст скрипта воспринимается как запрос на **дополнительный контент**, формируя новые упражнения без дублирования уже имеющихся блоков.

5. **Кнопка отмены генерации (`↩ Undo Generation`)**:
   - Фиксируются идентификаторы добавленных блоков последней генерации.
   - Сразу после завершения отображается кнопка `↩ Undo Generation (Remove X tasks)`.
   - По клику все блоки этой генерации удаляются, урок возвращается к точному исходному состоянию.

6. **Автодобавление новых слов в список (`Words`)**:
   - Все новые слова и фразы, появившиеся в сгенерированных заданиях, автоматически добавляются во вкладку `Words` урока в виде карточек `wordcard`.

7. **Лимит до 30 упражнений за раз и скрытие стрелок**:
   - В поле `Count` выставляется жесткий лимит `max="30"`, стрелки скрыты в CSS (`appearance: textfield;`).
   - Число задает итоговое количество генерируемых упражнений, распределяемых по выбранным типам квизов.
