## 1. Точная формулировка проблемы и анализ первопричины

- **Проблема**: В личной переписке сообщения собеседника (в частности, сообщения 3–5 на предоставленном скриншоте) отображаются на правой стороне экрана с фоном собственных сообщений (`is-own`) и с аватаром текущего пользователя вместо аватара фактического отправителя.
- **Первопричина 1 (Определение принадлежности `isOwnMessage`)**:
  В функции `isOwnMessage` проверка:
  ```javascript
  if (data?.profile?.name && m?.sender && String(m.sender) === String(data.profile.name)) return true;
  ```
  срабатывает по совпадению имени пользователя, даже если у сообщения указан чужой `senderId`, отличный от `myAccountId()`. В ситуации, когда у собеседника то же отображаемое имя (например, аккаунты *Tsovak* и *TsovakDev* с общим именем «Tsovak Palakian»), все входящие сообщения помечаются как исходящие (`is-own = true`).
- **Первопричина 2 (Отрисовка аватара в `syncDays`)**:
  В функции `syncDays` при наличии класса `is-own` идентификатор автора безусловно заменяется на `myAccountId()`:
  ```javascript
  const id = own ? ((typeof myAccountId === 'function' ? myAccountId() : '') || message.senderId) : message.senderId;
  ```
  Из-за этого вместо аватара собеседника генерируется аватар текущего авторизованного пользователя и выносится вправо.

## 2. Поэтапный чеклист реализации

- 🟩 **Этап 1: Коррекция логики идентификации авторства `isOwnMessage`**
  - Приоритет проверки `senderId`: если `m.senderId` передан и не совпадает с `myAccountId()`, функция гарантированно возвращает `false` без отката к неточному сравнению строковых имен.
  - Сохранение отката к имени `data.profile.name` исключительно для архивных сообщений, где `m.senderId` полностью отсутствует (`null`/`undefined`/`''`).
- 🟩 **Этап 2: Изолированная коррекция логики маленького чата в `syncMiniTimeline`**
  - Автономное определение `own` по `dataset.senderId` и `myAccountId()` вместо слепого чтения класса родителя.
  - Сохранение аватара/инициалов собеседника слева от входящих сообщений (`chat-mini-msg-row other`) и корректного правого позиционирования исходящих сообщений (`chat-mini-msg-row own`).
- 🟩 **Этап 3: Сборка и верификация ассетов**
  - Успешная пересборка бандла `npm run build:preview` и ассетов `ops/build-learning-production-assets.mjs`.
  - Запуск модульных тестов `node --test test/test-chat-presentation.mjs` (15 из 15 пройдены).
  - Создание и успешный прогон комплексного визуального теста `node --test test/test-chat-dual-author-separation-visual.mjs` во всех трех темах (`sky`, `dark`, `sand`).
