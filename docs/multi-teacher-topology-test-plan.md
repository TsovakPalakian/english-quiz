# План тестирования расширенной топологии (2 Developer, подгруппы, по 3 преподавателя и по 5 учеников)

## Цель
Создать комплексный автоматический интеграционный тест, проверяющий работу системы и разграничение прав доступа при масштабировании:
1. **2 аккаунта DEVELOPER**: оба имеют полный доступ ко всей системе, группам, преподавателям и ученикам.
2. **По 2 подгруппы в группе/уровне**: A1 (A1 Alpha Morning, A1 Beta Evening) и B1 (B1 Weekend Group, B1 Intensive Group).
3. **По 3 преподавателя в каждой подгруппе** (всего 12 преподавателей): совместное владение группой, видимость коллег внутри одной группы и изоляция от других преподавателей.
4. **По 5 учеников в каждой подгруппе** (всего 20 учеников): видимость учеников преподавателями группы, корректное отображение списков.
5. **Проверка безопасности и изоляции**:
   - Преподаватель видит только свои подгруппы, только своих учеников и только своих коллег по подгруппе.
   - Запрет перехода на страницу чужого преподавателя.
   - Разработчики видят всех участников и все подгруппы без ограничений.

## Чеклист реализации
- 🟩 1. Разработка тестового сценария и топологии в `test/test-multi-teacher-topology-ui.mjs`

- 🟩 3. Локальный прогон теста и верификация через `npm run check` (все 167 скриптов успешно пройдены)
