# План реализации гида реального наблюдения созвездий (Real Sky Observer Guide)

## Назначение задачи
1. Реализовать интерактивное модальное окно наведения на созвездия в реальном небе (Real Sky Observer Guide / Sky Finder) с расчетом истинных горизонтальных координат для местоположения наблюдателя:
   - Компасный азимут направления взгляда (Azimuth).
   - Высота над линией горизонта в градусах (Altitude).
   - Угол наклона фигуры созвездия относительно плоскости горизонта (Parallactic Sky Tilt).
   - Суточный график видимости (время восхода, время кульминации на максимальной высоте, время захода).
   - Практическая текстовая подсказка для визуального поиска объектов на ночном небе.
2. Реализовать вкладку списка созвездий, видимых над горизонтом прямо сейчас (Visible Now in Sky):
   - Автоматический расчет высоты для всех объектов каталога.
   - Фильтрация созвездий с высотой более 0 градусов.
   - Сортировка по убыванию высоты к зениту.
   - Двухколоночная сетка карточек созвездий с переходом к индивидуальному гиду в один клик.
3. Доработать эргономику и геометрию карточки инспектора созвездий:
   - Удаление лишней кнопки компаса из верхней строки бейджей.
   - Замена текста переключателя на чистый `more` (без многоточия) и чистый `less`.
   - Центрирование векторного перекрестия кнопки закрытия через точные координаты SVG.
   - Размещение кнопки вызова гида `Find in Sky Tonight` с бейджем `LIVE` строго в нижней части тела карточки под описанием.
4. Доработать панель наблюдателя:
   - Название населенного пункта `📍 Yerevan` на первой строке.
   - Географические координаты `40.2° N, 44.5° E` строго на второй строке без скобок с запретом переноса строк.
   - Кнопка спутниковой геолокации `Use GPS` с отступом и вертикальным разделителем перед блоком времени.
5. Обеспечить фоновое живое обновление данных каждые 60 секунд при открытом окне гида с отображением индикатора `LIVE` и корректным освобождением ресурсов при закрытии окна.

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>: Запрещено задевать, модифицировать или ломать функционал, не относящийся к текущей задаче. Выполняемые задачи строго и изолированно должны задевать только свой функционал (астрономические расчеты горизонтальных координат, карточка инспектора созвездий, модальное окно гида наблюдения и связанные стили темной темы). Любые смежные модули авторизации, тестирования, звукового движка и взаимодействия с сервером сохраняются без изменений.

## Этапы выполнения

### Этап 1: Математический аппарат горизонтальных координат
- Реализация функций расчета юлианской даты и гринвичского звездного времени (GMST).
- Расчет местного звездного времени (LST) с учетом долготы наблюдателя.
- Расчет часового угла (Hour Angle) и сферических координат: высоты над горизонтом и азимута по сторонам света.
- Расчет параллактического угла для вычисления угла наклона фигуры созвездия относительно местного горизонта.
- Расчет моментов восхода, кульминации в наивысшей точке и захода созвездия.

### Этап 2: Эргономика карточки инспектора
- Исключение кнопки компаса из верхней строки карточки.
- Замена текста переключателя на `more` и `less` без многоточия.
- Внедрение отцентрированного векторного значка SVG в кнопку закрытия.
- Добавление кнопки запуска гида `Find in Sky Tonight` с бейджем `LIVE` строго в нижнюю часть развернутой карточки.

### Этап 3: Модальное окно гида и панель наблюдателя
- Построение структуры модального окна с табами `Target Constellation` и `Visible Now in Sky`.
- Стилизация панели наблюдателя: название города на первой строке, координаты на второй строке без скобок с запретом переноса строк, отступ и разделитель для кнопки `Use GPS`.
- Интерактивная обработка состояний кнопки `Use GPS` (поиск, активное состояние с получением координат, ошибка).
- Формирование трех графических инструментов наведения на базе векторных элементов SVG.
- Реализация представления созвездия под горизонтом с янтарным предупреждением и таймером обратного отсчета до восхода.

### Этап 4: Вкладка видимых созвездий и живое обновление
- Вычисление высоты для всех созвездий каталога на текущую минуту времени.
- Фильтрация объектов с положительной высотой и упорядочивание по убыванию к зениту.
- Вывод сетки карточек с указанием градусов высоты и компасного направления.
- Переключение на индивидуальный гид выбранного объекта по клику на карточку.
- Запуск таймера обновления каждые 60 секунд при активном окне и его очистка при закрытии.

### Этап 5: Сборка и тестирование
- Сборка клиентских ассетов командой `npm run build:preview`.
- Создание модульных тестов для проверки точности формул астрономических координат.
- Создание визуальных тестов соответствия интерфейса утвержденным макетам.
- Верификация чистоты рабочего пространства.
