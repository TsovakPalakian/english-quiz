# Исправление счётчиков импортированной истории чата

## Граница

<span style="color: red; font-weight: bold;">WARNING</span> Правка ограничена Durable Object чата и его тестом. Не изменять маршруты аккаунтов, сообщения, интерфейс или логику новых сообщений.

## Этапы

- 🟩 При следующем обращении к уже импортированной комнате один раз установить курсоры чтения на последнее импортированное сообщение каждой категории.
- 🟩 Сохранить маркер миграции, чтобы новые сообщения после исправления продолжали увеличивать счётчики.
- 🟩 Добавить регрессионный тест для комнаты с устаревшими импортированными счётчиками.

## Проверка

Пользователь запускает `node --test test/test-chat-durable.mjs` для проверки Durable Object чата.
