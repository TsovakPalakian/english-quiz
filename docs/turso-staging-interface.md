# Локальный тестовый интерфейс Turso

Production не переключён. `src/worker.js`, основной клиент, D1 и R2 на этом
этапе не менялись. Новый адаптер `src/turso-study.mjs` пока не импортируется
рабочим Worker. Стенд читает/пишет только `english-quiz-test` из `.dev.vars`.

## Запуск

```bash
node scripts/run-turso-stage.mjs
```

Открыть локальную ссылку с `#code=…`, напечатанную командой. Этот код разрешает
выбрать демонстрационную роль только на локальном стенде; это не JWT Turso
и не пароль аккаунта. Сессия живёт час. Сервер слушает только `127.0.0.1:8788`,
не публикует файлы проекта/секреты, проверяет Host и Origin. Остановить Ctrl+C.
Секреты Turso браузеру не передаются. `staging/` исключён из Cloudflare assets.

Роли ADMIN/DEVELOPER/USER берутся из приватного снимка `accounts.json`, а не
из присланного клиентом поля role. Повторный вход/чтение production D1 не
выполняются. Это проверка логики прав с доверенными тестовыми сессиями,
**не проверка настоящих паролей, входа или актуальности ролей в D1**.

## Реализовано

- Карточки с сервера, фильтр слова/урока, страницы по 40, без фонового polling.
- Save отправляет только `changes.ru`, ID операции и ожидаемую версию.
- Новые/редактируемые квизы записываются отдельно; удаляется один квиз по ID,
  а не отправляется весь массив `cardQuizzes`. Содержание раскрывается кликом.
- Общие определения teacher/dev редактируют, student только читает. Сервер
  запрещает записи ученику независимо от видимости кнопок/поля role в запросе.
- Чужие личные карточки не выдаются. Shared-профиль существующей пары сохранён.
  Draft/hidden-уроки скрыты от ученика, индивидуальные правила доступа учитываются.
- Удаление — tombstone (`deleted_at`), не необратимое стирание импортированных
  данных. Списки и чтение по ID исключают tombstone во всех сессиях.
- Запись и квитанция операции сохраняются одной транзакцией. Проверка версии
  защищает от перезаписи чужого изменения, повтор того же ID — от дублей.
  Временная таблица проверки явно удаляется до COMMIT, в том числе для
  соединений, которые провайдер может повторно использовать.
- Неподтверждённая операция сохраняется локально для ручного повтора тем же ID.
  Автоматического восстановления удалённых объектов из localStorage нет.

Квитанции действуют 24 часа. Автоматического повтора через сутки нет; при
очень старом неподтверждённом запросе сначала проверить серверное состояние.
Квизы пока сохраняют legacy-связь по слову; определения карточек имеют ID.
Редактор квизов здесь показывает поля в JSON, без полного игрового движка.
Редактирование чужих личных материалов учителем, управление учениками,
реальный D1-login и остальные экраны основного приложения ещё не подключены.
Не разворачивать этот demonstration-сервер как публичный backend.

## Проверки

```bash
node --test scripts/test-turso-stage.mjs
# Пока локальный сервер работает:
node scripts/check-turso-stage-live.mjs --prepare
node scripts/check-turso-stage-live.mjs --check
node scripts/check-turso-stage-live.mjs --cleanup
```

Автономные тесты проверяют HTTP-права/CSRF, приватность, версии, параллельный
повтор, потерю ответа после COMMIT, сохранение и удаление карточек/квизов.
Live-проверка создаёт только UUID-помеченные временные уроки/карточки в TEST
Turso. ID записаны **до** создания в приватном `rollback/turso-stage-fixture.json`.
При сетевом сбое не удалять журнал: после восстановления связи выполнить
`--cleanup`. Очистка удаляет только указанные временные сущности и их квитанции,
сверяет исходные количества и `foreign_key_check`. Папка rollback игнорируется
Git и Cloudflare assets. Live-проверка не вызывает production D1/R2.
