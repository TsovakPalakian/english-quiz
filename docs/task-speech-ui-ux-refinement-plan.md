# План поэтапной настройки и полировки UI/UX вкладки Speech

> [!WARNING]
> <span style="color: red; font-weight: bold;">WARNING</span>
> **ПРЕДУПРЕЖДЕНИЕ О ЗАТРАГИВАНИИ СМЕЖНОГО ФУНКЦИОНАЛА И НЕПРИКОСНОВЕННОСТИ СИСТЕМЫ:**
> Данная задача строго изолирована и касается исключительно визуального оформления и эргономики интерфейса (UI/UX) панели речевой практики (`#lmSpeechPanel`):
> 1. Стилизация плашки статуса провайдера (`speech-provider-banner`).
> 2. Эргономичное оформление пустого состояния (`speech-empty-card`) при отсутствии речевых заданий у урока с сокрытием пустого селектора задач.
> 3. Оформление аккордеонов (`details / summary`) в стиле дизайн-системы платформы с поддержкой переключения тем (`sky`, `dark`, `sand`) через CSS-переменные `--bg`, `--card`, `--ink`, `--mute`, `--line`, `--acc`.
> 4. Оформление формы создания речевых заданий (`Create a lesson speech task`) с двухколоночной сеткой полей, интуитивными отступами и кнопкой действия.
> 5. Оформление панели активного задания, элементов записи микрофона, индикаторов прогресса, карточек артикуляционных подсказок и графиков.
>
> Строго запрещено затрагивать, модифицировать или нарушать смежный функционал:
> - Протоколы работы Web Audio API, кодирование PCM16 WAV 16 кГц, проверку согласия пользователя (consent).
> - Интеграцию с провайдерами Azure Speech, Cloudflare Whisper, диалоговыми сервисами и систему лимитов/квот.
> - Таблицы базы данных (`qr_speech_tasks`, `qr_speech_attempts`, `qr_speech_shares`, `qr_speech_disputes`).
> - Работу соседних вкладок урока (`Classwork`, `Homework`, `Lesson PDF`, `Day quiz`, `Focus Mode`, `Voice Mode`).
