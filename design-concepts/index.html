How to use

Как пользоватьсяHow to use

StudyStudy

На Study сначала включен только Flip. Остальные типы открываются через .... Round проходит каждый выбранный тип на одной карточке. Mix берет один случайный тип. Start начинает занятие. Exam и Mistakes берут те же карточки. Flip в экзамен не входит. Экзамен не сдан при двух ошибках или через 20 минут.

On Study, only Flip starts on. The other types open from .... Round runs every selected type on one card. Mix picks one random type. Start begins the session. Exam and Mistakes use those same cards. Flip is not on the exam. The exam fails at two mistakes or after 20 minutes.

Когда карточка выученаWhen a card is learned

Карточка выучена, только когда пройден каждый включенный проверяемый тип. Flip вы оцениваете сами: он не закрывает карточку. Ошибка остается, пока этот тип не отвечен верно четыре раза подряд.

A card is learned only when every enabled checkable type is passed. Flip is self-rated: it does not close the card. A mistake stays until that type is answered correctly four times in a row.

Russian input looks up the English word. English input looks up the Russian translation. On Add a word, the word goes to My words. On a lesson, the same field keeps the word on that lesson. If there is no such word or phrase, the page says No such word or phrase.
